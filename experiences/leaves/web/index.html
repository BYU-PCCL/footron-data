Simulated color change

Every fall, leaves change color based on measurable environmental conditions. Depending on which chemicals are present in a leaf at a given time, oranges, reds, yellows, and browns manifest differently. This program visualizes those chemical changes in real time.

Try scanning the QR code to change the amount of cloud cover, wind, and monthly temperature to see how the leaf reacts!
