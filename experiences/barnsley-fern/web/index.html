Barnsley’s Fern

There is no fern in this program — no leaf, no stem, no outline anywhere in the code. There is one moving point, four rules for moving it, and a loaded die. Every throw picks a rule, the rule slides, shrinks and turns the point to somewhere new, and a speck of light is left where it lands. Seven million throws later the specks have filled in everywhere the walk can reach, and that reachable set is a fern.
space pause the walk · n start the walk over · m roll a random plant · r back to Barnsley’s numbers
