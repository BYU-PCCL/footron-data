Skip list

The Skip
List

A sorted linked list with express lanes built over the top of it. A coin flip decides which values get one, and that is the whole of its balancing strategy.

Normal linked lists have slow lookup time, even when the data is sorted. Self-balancing trees (like Red-Black or AVL trees) have quick lookup but are hard to implement and cause problems when a program is multi-threaded.

Skip lists can be a great solution to this. The structure stays balanced probabilistically by randomly deciding whether or not to add a "shortcut" to that point in the data.

The idea

  • The bottom level is an ordinary sorted linked list. Every level above it is a shortcut over the top.
  • How tall a value's tower is comes from coin flips — there is no rule keeping it balanced.
  • A search drops down a level the moment the next value overshoots. O(log n), with nothing to rebalance.
